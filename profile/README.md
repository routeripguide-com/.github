# RouterIPGuide — Open Networking & Router Gateway Reference

Welcome to the official GitHub organization for [RouterIPGuide.com](https://routeripguide.com/), an independent reference portal and diagnostic suite for computer networking hardware.

### 🌐 Live Web Utilities
- [Interactive Router Brand Directory](https://routeripguide.com/brand) — Verified factory credentials and login steps for 100+ OEMs.
- [Private IPv4 Gateway Lookup](https://routeripguide.com/ip) — Dedicated guides for 192.168.1.1, 192.168.0.1, 10.0.0.1, and 192.168.8.1.
- [IPv4 CIDR Subnet Calculator](https://routeripguide.com/tools/subnet-calculator) — Calculate network bounds, host ranges, and broadcast addresses.
- [Ping Latency & Jitter Diagnostic](https://routeripguide.com/tools/ping-test) — Real-time browser-based latency analyzer.
- [Wi-Fi QR Code Generator](https://routeripguide.com/tools/wifi-qr-generator) — Instant WPA2/WPA3 configuration generator.

### 📊 Open Datasets & Repositories
- [Kaggle Dataset](https://www.kaggle.com/datasets/routeripguide/router-default-gateways-csv) — Machine-readable default credentials.
- [Hugging Face](https://huggingface.co/routeripguide) — Networking dataset mirrors for LLM grounding.
