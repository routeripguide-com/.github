# Router IP Guide

Router login guides and free network tools.

Router IP Guide explains how to log in to your router and manage your home network. It covers common admin addresses such as 192.168.1.1, 192.168.0.1 and 10.0.0.1, step-by-step guides for TP-Link, Netgear, ASUS, D-Link and Linksys routers, and fixes for when the login page won't load.

## Free tools

- Subnet calculator
- Port checker
- Ping test
- Wi-Fi QR code generator
